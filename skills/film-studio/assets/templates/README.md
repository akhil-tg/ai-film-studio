# Templates

The nine files the pipeline actually uses. Copy into the project folder; names map 1:1 except episode files (→ `ep01/`).

| Template | Destination |
|---|---|
| `project.md` | `<project>/project.md` |
| `story.md` | `<project>/story.md` |
| `characters.md` | `<project>/characters.md` |
| `locations.md` | `<project>/locations.md` |
| `storyboard.csv` | `<project>/storyboard.csv` |
| `script.md` | `<project>/script.md` |
| `flow-agent.md` | `<project>/flow-agent.md` |
| `script.md` | `<project>/ep01/script.md` |
| `prompts.md` | `<project>/ep01/prompts.md` |

## Optional

For other formats and deeper continuity, not part of the core flow:

`00-brief.md` · `series.md` · `plan.md` · `continuity.md` · `world.md` · `style.md` · `motifs.md` · `narration.md` · `caption.md` · `character-sheet.md` (per-angle fallback for character references)

`story-scenes.csv` and `storyboard.example.csv` are filled examples — reference only, don't copy.

Templates are scaffolding. Empty fields are questions to ask, not blanks to invent.
