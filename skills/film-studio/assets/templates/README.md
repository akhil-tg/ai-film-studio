# Templates

Copy into the project folder the skill creates. Filenames map 1:1, except bible files (→ `bible/`) and unit files (→ `unit-01/`, `ep01/`, `seq01/` …).

| Template | Destination |
|---|---|
| `project.md` | `<project>/project.md` |
| `00-brief.md` | `<project>/00-brief.md` |
| `series.md` | `<project>/series.md` (series) |
| `plan.md` | `<project>/plan.md` (single piece) |
| `continuity.md` | `<project>/continuity.md` |
| `story-scenes.csv` | `<project>/storyboard/story.csv` |
| `characters.md` | `<project>/bible/characters.md` |
| `character-sheet.md` | `<project>/bible/character-sheets.md` |
| `locations.md` | `<project>/bible/locations.md` |
| `flow-agent.md` | `<project>/bible/flow-agent.md` |
| `world.md` | `<project>/bible/world.md` |
| `style.md` | `<project>/bible/style.md` |
| `motifs.md` | `<project>/bible/motifs.md` |
| `story.md` | `<project>/<unit>/story.md` |
| `narration.md` | `<project>/<unit>/narration.md` (documentary only) |
| `storyboard.csv` | `<project>/<unit>/storyboard.csv` |
| `script.md` | `<project>/<unit>/script.md` |
| `prompts.md` | `<project>/<unit>/prompts.md` |
| `caption.md` | `<project>/<unit>/caption.md` |

`storyboard.example.csv` is a filled example — reference only, don't copy.

Templates are scaffolding. Empty fields are questions to ask, not blanks to invent.
