# Format — YouTube Short

Vertical, but a different audience and a different algorithm. Closer to a Reel than to a film.

## At a glance

| | |
|---|---|
| **Aspect** | 9:16, 1080×1920 |
| **Length** | 20–60s ideal. Hard cap 3 min; don't use it. |
| **Shots** | 5–12, cut to 2–4s |
| **Generations** | 5–10 clips |
| **Shot grammar** | `core/shot-grammar-vertical.md` |
| **Structure** | hook → single idea → payoff |

## How it differs from a Reel

| | Reel | YouTube Short |
|---|---|---|
| **Series** | common, expected | rare — usually one-off |
| **Loop** | strong signal | helps, less critical |
| **Title text** | burned in | burned in, but the platform also shows one |
| **Subscribe CTA** | weak | works, keep it to the last 2s |
| **Search** | hashtags | title and spoken words are indexed — say the topic out loud |
| **Safe zones** | bottom ~350px blocked | bottom blocked, right side has buttons |

## Structure

```
hook (0–2s) → one idea → proof / turn → payoff
```

A Short carries **one idea**. If you have two, that's two Shorts.

The single most reliable shape: **claim, then demonstrate.** State something surprising in the first two seconds, spend the rest proving it.

## Indexing

YouTube transcribes Shorts. So:

- Put the topic in the **first spoken sentence**.
- Put it in the **title** and in **burned text**.
- Describe it plainly in the description, one line.

This is free distribution that Reels doesn't give you. Use it.

## Deliverable deltas

- `caption.md` → title (under 60 chars, keyword first), description line, cover frame
- `script.md` → ensure the first spoken line names the topic

## Failure modes

1. Treating it as a truncated long video
2. Two ideas in 45 seconds
3. No spoken or on-screen keyword, so it's unsearchable
4. CTA at the start, killing retention
5. Burning in a title that duplicates the platform's own title
