# Format — Documentary / faceless narration

Voiceover-led. The script is narration + b-roll, not scenes and dialogue.

## At a glance

| | |
|---|---|
| **Aspect** | 16:9 (or 9:16 for social cuts) |
| **Length** | 3–15 min |
| **Shots** | 40–120 b-roll shots |
| **Structure** | narration outline → b-roll per line |
| **Shot grammar** | matching aspect file |

## Why "faceless"

AI cannot produce a credible talking head for more than a few seconds — mouths drift, eyes wander, and the uncanny effect is immediate. So the reliable AI documentary is **narration over b-roll**, with no on-camera presenter.

If the user wants interviews, tell them plainly: talking heads are the weakest AI output. Suggest narration + b-roll, or real footage for any interview.

## Structure

```
cold open (a striking image + one line)
→ thesis (what this piece claims)
→ 3–5 chapters, each a question answered
→ turn (the complicating fact)
→ close (return to the cold open image)
```

Each chapter is 45–120 seconds: claim → evidence → image that proves it.

## Script format — narration + b-roll

This is the key difference. Write it as a two-column document:

| Narration | Visual |
|---|---|
| "In 1969, a computer the size of a room had less memory than your watch." | Vintage mainframe, blinking panels, slow push in |
| "It still beat us at chess." | Cut: chess board, hand moving a piece, extreme close-up |

Rules:

- **150 words ≈ 60 seconds.** Budget by word count.
- **Never describe what the image shows.** Add what it can't.
- **One image per sentence** is the safe ratio. Two images per sentence if it's a fast montage.
- **Write the cold open last.** It's the hardest and depends on the whole piece.

## Visual language

Documentaries run on **motifs**, not characters. Fill `story.md`:

- Recurring image types (archives, maps, hands, textures)
- A colour grade that implies era or mood
- One repeated shot that bookends the piece
- Motion rule: slow pushes and static holds, not whips

## Accuracy

This format makes factual claims, so:

- Every number, date, and name must be verified by the user before publishing.
- Flag anything you're unsure of with `[VERIFY]` in the script.
- Never invent a statistic to make a sentence land. Cut the sentence.

## Deliverable deltas

- `story.md` → thesis, audience, what the viewer learns
- `plan.md` → chapter outline with claims and evidence
- `unit/narration.md` → replaces `story.md`; two-column narration + visual
- `story.md` → recurring imagery and grade
- `caption.md` → title, thumbnail text, description with sources

## Failure modes

1. Narration describing the picture
2. Talking heads that drift
3. Unverified claims stated confidently
4. Wall-to-wall music with no room to think
5. No thesis — a sequence of facts is not a documentary
