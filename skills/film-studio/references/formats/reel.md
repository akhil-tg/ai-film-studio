# Format — Reel shorts (vertical, 30–90s)

> For one long story told across 10–40 episodes, read `reel-arc.md` instead.
> This file is the craft of a single 30–90s episode.

Instagram Reels. The most demanding pacing of any format.

## At a glance

| | |
|---|---|
| **Aspect** | 9:16, 1080×1920 |
| **Length** | 30–90s (60 is the sweet spot) |
| **Shots** | 6–12, cut to 2–4s |
| **Generations** | 6–10 clips of 10s, trimmed down |
| **Shot grammar** | `core/shot-grammar-vertical.md` |
| **Structure** | hook → setup → turn → payoff → hook out |

## Structure — 60s default

| Time | Beat | Job |
|---|---|---|
| 0–3s | Cold open | Mid-action or mid-sentence. Never a title card. |
| 3–15s | Setup | Character + want + obstacle, economically |
| 15–45s | Turn | Escalate twice |
| 45–57s | Payoff | The emotional hit |
| 57–60s | Hook out | A question |

**30s version:** 0–2 hook · 2–8 setup · 8–20 turn · 20–27 payoff · 27–30 hook out.
**90s version:** add a quiet beat where the character decides something, before the payoff.

## Episodic variant

If it's a series, `plan.md` holds the season arc and each episode ends on a **question** answered by the next.

- Each episode changes the answer to the season question.
- Obstacle escalates: distant → present → personal → unavoidable.
- Episode 1 must be the strongest. Nobody starts at episode 4.

## The hook

First 2 seconds decide everything. Valid: interruption, impossible image, wrong statement, direct address.

Invalid: logo, city shot, waking up, title card, "In a world where".

## Text on screen

- Carry the one line that matters — many viewers start muted.
- Max 6 words per card, inside the safe band.
- Burned captions for dialogue in the first 3 seconds especially.

## Loop

If the last frame matches the first, the Reel replays and retention rises. Worth designing deliberately: a 1-second return-to-start is free retention.

## Deliverable deltas

- `caption.md` → caption, 5–8 hashtags, cover frame, on-screen text map
- The **cover frame** must read as a question at thumbnail size

## Failure modes

1. Slow first second — the entire piece is dead
2. Explaining the premise in dialogue
3. Three or more characters in 60 seconds
4. Uniform shot length
5. Text outside the safe band
6. No reason to watch episode 2
