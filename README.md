# ai-film-studio

A ChatGPT plugin for making **AI films in Google Flow** — everything up to the render.

You bring an idea. ChatGPT builds the story, the locked character bible, the structure, the storyboard, the screenplay, and copy-paste Flow prompts. You generate the clips, edit, publish.

No video or image is generated by ChatGPT. No API keys. ChatGPT is the writer's room and shot planner; Flow is the camera.

## Ten choices, one skill

| Format | Aspect | Length |
|---|---|---|
| Reel movie (series) | 9:16 | 2–3 min per episode |
| Reel shorts (series) | 9:16 | 30–90s per episode |
| Single Reel | 9:16 | 30–90s |
| YouTube Short | 9:16 | 20–60s |
| Landscape short film | 16:9 | 3–15 min |
| Long-form episode | 16:9 | 5–20 min |
| Ad / commercial | 9:16 or 16:9 | 15–60s |
| Music video | 16:9 or 9:16 | song length |
| Trailer / teaser | 16:9 | 30–90s |
| Documentary / faceless | 16:9 or 9:16 | 3–15 min |

Reels split three ways because they're different jobs. A **Reel movie** is one long story across 10–40 episodes, with acts mapped to episode ranges. **Reel shorts** are standalone episodes. A **Single Reel** is one unit with no series overhead.

One skill, not ten — the format is a setting, and each format has its own craft reference. Fewer, better-targeted instructions beat ten half-maintained skills.

## Why it exists

Four things ruin AI films: **inconsistent characters**, **shots that can't be generated**, **structure too big for the runtime**, and **continuity drift**. This plugin fights all four:

- **Locked bible** — descriptions pasted verbatim into every prompt, so faces don't drift
- **Locked voice** — the same for speech, which drifts just as badly
- **Shot discipline** — one action, one camera move, ≤10s generations cut to 2–4s
- **Format-aware structure** — a 60s Reel doesn't get three acts; a 10-min film does
- **Continuity log** — episode 4 can't contradict episode 1

## Install

Four routes, easiest first.

### 1. Local skill folder — no admin, works today

Copy the skill folder into your user skills directory:

```
skills\film-studio\   →   %USERPROFILE%\.agents\skills\film-studio\
```

On macOS or Linux:

```
skills/film-studio/   →   ~/.agents/skills/film-studio/
```

Restart the ChatGPT desktop app. The skill appears under **Skills** and can be used in the desktop app, Codex CLI, and the IDE extension.

### 2. GitHub marketplace — needs a workspace admin

The repo is a plugin *and* a marketplace. In the ChatGPT admin console:

**Admin console → Plugins → Marketplaces → import** `akhil-tg/ai-film-studio`

It syncs daily. In Codex:

```bash
codex plugin marketplace add akhil-tg/ai-film-studio
```

### 3. Upload the plugin ZIP — workspace admin only

Download [`dist/ai-film-studio-plugin.zip`](dist/ai-film-studio-plugin.zip), then:

**Admin console → Plugins → Add → Upload plugin**

Rebuild after editing:

```bash
powershell -ExecutionPolicy Bypass -File scripts/build-plugin-zip.ps1
```

### 4. Plugin Creator — personal accounts

Personal ChatGPT accounts can't upload plugin ZIPs. Instead, install **Plugin Creator** from the plugin directory and mention `@plugin-creator`, then describe the plugin or hand it this repo.

## Use

Mention it, or just describe the idea:

```
@AI Film Studio start a Malayalam reel movie about a boy who finds a phone that shows the future
```

Then it walks you through, in this order, stopping for approval:

1. **Language**
2. **Your storyline** — you give it, it develops the story and the continuity rules
3. **Platform** — Instagram or YouTube
4. **Format** — it recommends one from your story, with a reason
5. **Cast** — humans, or anthropomorphic animals
6. **Sound** — music, or no music (effects always)
7. **Character build** — one plain prompt per character, generated in Flow
8. **Story + continuity** → `00-brief.md`, `series.md`
9. **Storyboard of the whole story** → `storyboard/story.csv`
10. **Script of the whole story** → `script-full.md`
11. **Locations and props** → plates and object prompts
12. **Episode 1** → story, script, scene count, Flow agent instructions, scene-by-scene prompts

No slash commands — "start" and "next" are the whole vocabulary, plus `@AI Film Studio` when you want it explicitly.

### Answering questions

Every option list is **numbered**. Reply with a digit — `1`, `2`, `3` — or the name. The last option is always "something else", so you're never trapped by the suggestions.

The first question in a new project is always the **language**, because it changes the dialogue, the on-screen text, and the voice — not just the translation.

## Reel movies

The format it was built for: one story, 10–40 episodes, 2–3 minutes each, watched in order.

It asks how many episodes and how long, then writes a brief and stops. After approval comes `series.md` — the act map plus a one-line index of every episode:

| # | Logline | Cliffhanger | Status |
|---|---|---|---|
| 1 | | | written |
| 2 | | | planned |

That file is the whole handover. A new chat reads it and knows exactly where the film is, so `continue episode 12` works from nothing else.

Built into the format:

- **Episode 1 must stand alone** — satisfying even if nobody returns
- **No recap openings** — the cold open works without context
- **One turn per episode** — filler is a scene with no change
- **Cliffhanger types rotate**, or none of them land
- **Acts mapped before episode 1** — no sagging middle
- **One episode at a time, in order** — drift compounds

## Animals

If you pick animals, they're **anthropomorphic**: upright, speaking, clothed, using phones — they just look like animals. Species is cast for temperament, with the reasoning shown:

| Character | Animal | Why |
|---|---|---|
| Ravi, anxious | hare | small, quick, always watching over its shoulder |
| Amma, immovable | elephant | slow, enormous, impossible to argue with |
| The caller, unseen | snake | heard before seen |

Swap any of them. From then on one rule holds: **no humans**. Not in the background, not in a crowd, not reflected in a window.

## Character sheets

Right after casting, every character gets **one plain prompt**: a single paragraph you copy into Flow as-is. It asks for a reference sheet — front, three-quarter, side and back, same scale, same character — with the full description, wardrobe and one distinguishing mark baked in.

No labels, no fields, no "front view:" sub-prompts. One block, one character.

If the four views come back as four different people, the fallback splits it: keep the front, then generate the rest from it as an image reference.

You do this once, then attach `refs/<name>-sheet.png` to every shot. Locations and props work the same way.

**The plugin never generates images.** It writes prompts, refuses to draw, and never claims to have seen the result.

## Dialogue

Two things it won't do: write prose read aloud, or explain the theme.

- **Spoken, not written.** Contractions, fragments, interruptions, people answering the wrong question.
- **Punch lines.** One per scene, ten words or fewer, the last line before the cut. Reversal, threat, confession, refusal, callback, joke with teeth.
- **Read-aloud test.** If you run out of breath, it's too long. If any character could say it, it isn't dialogue.

## Sound

Right after the cast it asks one question: **music, or no music?** The answer holds for the whole film.

- **No music** doesn't mean silence. Thunder, doors, cars, footsteps, rain, fans — every sound the world makes still gets written, shot by shot. Every prompt ends `No music.`
- **Music** is one track per episode: enters after the hook, drops out for the punch line.

## Flow's four durations

Flow generates **4, 6, 8 or 10 seconds** — nothing else. Ask for 5 and you get something else.

Final cuts are 2–4s, so shots are generated long and trimmed. Anything longer than 10 seconds is extended in 10-second steps, up to 40.

## Before you generate

Flow gets one standing instruction block per project — style, continuity, voice, no humans if animals, music policy, no text, the four durations. Paste it once, before the first video, and leave it alone.

Then prompts arrive **scene by scene**: one scene per message, each shot a single plain block you copy without editing.

## Plain prompts

Every Flow prompt is one paragraph of continuous prose — 90–130 words covering the character, the action, the place, the camera, the light, the style, the dialogue and voice, the ambience and effects, the negatives, the duration and the ratio.

No labels, no bullets, no brackets, nothing to fill in. The metadata — duration, uploads, task mode — sits above the block, never inside it.

## Other languages

You can make a film in **any language Flow speaks** — Malayalam, Tamil, Hindi, and so on. The split is simple:

> **Prompts are English. Dialogue is native.**

Scene, camera, lighting, and style are written in English, because that's what the model reads best. Spoken lines are quoted verbatim in the project language, in native script, inside the prompt:

```
He says in Malayalam: "അമ്മേ, എനിക്ക് പേടിയാകുന്നു."
Voice: low, warm, unhurried; Malayalam with a Thrissur accent.
```

No dubbing, no recording pass, no translation. Omni speaks the line itself.

Two things that matter more than you'd expect:

- **The voice line is locked** and pasted verbatim, exactly like a face description — otherwise the character sounds like a different person in every clip.
- **No subtitles by default.** They're added only if you ask. (On-screen hook text is not a subtitle.)

Malayalam has its own reference file: accents, voice locking, fonts for on-screen text, and Kerala visual vocabulary that keeps the film from looking like generic AI-India.

## Long sessions

The window fills faster than you'd expect — a storyboard plus its prompts is tens of thousands of tokens. Three episodes in one chat and the model starts inventing wardrobe.

Built into the skill:

- **One unit per chat.** It tells you when to start a fresh one.
- **Batches of 6–8 shots** for `storyboard.csv` and `prompts.md`.
- **No bible restatement** — only the lines a batch actually uses.
- **Files over pasted text**, wherever the host can write files.
- **Continuity as a log** — one line per unit, not prose.

What you do:

1. Put the project in a **Project** and keep the files there.
2. Start a **new chat per episode** and say `continue`.
3. Or just let it tell you — it will say when the unit is done.

## Honest limits

The plugin prompts Google Flow / Gemini Omni — it doesn't render anything itself. You still paste the prompts, pick the takes, and edit. What it removes is the blank page: structure, characters, shots, and prompts arrive ready to use.

- Flow's UI is manual. Nothing here automates generation.
- Character consistency is *good*, not perfect. Same references + verbatim descriptions get you most of the way.
- Voices drift between clips the same way faces do — the fix is a locked voice descriptor, not re-recording.
- Talking heads are AI's weakest output — documentaries here are narration + b-roll by design.
- Cost is real: a 10-minute film is ~150–200 generations with retries.
- Standalone skills run in the desktop app and Codex, not on chatgpt.com or mobile. Bundling it as a plugin is what reaches web and mobile.
- This is a pre-production tool. The edit is where a film is actually made.
