# ai-film-studio

A Claude plugin for making **AI films in Google Flow** — everything up to the render.

You bring an idea. Claude builds the bible, the structure, the storyboard, the screenplay, and copy-paste Flow prompts. You generate the clips, edit, publish.

No video is generated by Claude. No API keys. Claude is the writer's room and shot planner; Flow is the camera.

## Eight formats, one skill

| Format | Aspect | Length |
|---|---|---|
| Reel (episodic or one-off) | 9:16 | 30–90s |
| YouTube Short | 9:16 | 20–60s |
| Landscape short film | 16:9 | 3–15 min |
| Long-form episode | 16:9 | 5–20 min |
| Ad / commercial | 9:16 or 16:9 | 15–60s |
| Music video | 16:9 or 9:16 | song length |
| Trailer / teaser | 16:9 | 30–90s |
| Documentary / faceless | 16:9 or 9:16 | 3–15 min |

One skill, not eight — the format is a setting, and each format has its own craft reference. Fewer, better-targeted instructions beat eight half-maintained skills.

## Why it exists

Four things ruin AI films: **inconsistent characters**, **shots that can't be generated**, **structure too big for the runtime**, and **continuity drift**. This plugin fights all four:

- **Locked bible** — descriptions pasted verbatim into every prompt, so faces don't drift
- **Shot discipline** — one action, one camera move, ≤10s generations cut to 2–4s
- **Format-aware structure** — a 60s Reel doesn't get three acts; a 10-min film does
- **Continuity log** — episode 4 can't contradict episode 1

## Install

```bash
/plugin marketplace add "D:\CODING\Skill\ai-film-studio"
/plugin install ai-film-studio@ai-film-studio-marketplace
```

Dev mode, no install:

```bash
claude --plugin-dir "D:\CODING\Skill\ai-film-studio"
```

## Use

```
/ai-film-studio:start a boy finds a phone that shows the future, as a reel series
```

It asks up to three choice-based questions, writes a story brief, and **stops**. Once approved:

```
/ai-film-studio:next 1
```

Repeat per unit. Or just talk to it — the skill triggers on its own when you ask for a short film, storyboard, shot list, or Flow prompts.

## Honest limits

- Flow's UI is manual. Nothing here automates generation.
- Character consistency is *good*, not perfect. Same references + verbatim descriptions get you most of the way.
- Non-English dialogue should be recorded and dubbed, not generated.
- Talking heads are AI's weakest output — documentaries here are narration + b-roll by design.
- Cost is real: a 10-minute film is ~150–200 generations with retries.
- This is a pre-production tool. The edit is where a film is actually made.
