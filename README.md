# ai-film-studio

A ChatGPT plugin for making **AI films in Google Flow** — everything up to the render.

You bring a storyline. ChatGPT develops the story and continuity, casts it, writes the storyboard and script, builds character and location prompts, and hands you Flow prompts scene by scene. You generate the clips, edit, publish.

No image or video is generated by ChatGPT. No API keys. It writes; Flow shoots.

## Install

**1. Local skill folder — no admin**

```
skills\film-studio\   →   %USERPROFILE%\.agents\skills\film-studio\
```

macOS / Linux: `skills/film-studio/ → ~/.agents/skills/film-studio/`. Restart the ChatGPT desktop app.

**2. GitHub marketplace — admin**

**Admin console → Plugins → Marketplaces → import** `akhil-tg/ai-film-studio`

**3. Upload the ZIP — admin only**

Download [`dist/ai-film-studio-plugin.zip`](dist/ai-film-studio-plugin.zip) → **Admin console → Plugins → Add → Upload plugin**. Rebuild with `scripts/build-plugin-zip.ps1` after edits.

**4. Plugin Creator — personal accounts**

Personal accounts can't upload ZIPs. Install **Plugin Creator** and mention `@plugin-creator`.

## Use

Describe the idea, or say `start`:

```
@AI Film Studio start a Malayalam reel movie about a boy who finds a phone that shows the future
```

**Five setup questions, one at a time:**

1. **Language**
2. **Storyline** — you give it; it develops the story and the continuity rules
3. **Platform and format** — Instagram or YouTube, then it recommends one format with a reason
4. **Cast** — humans, or anthropomorphic animals
5. **Music** — yes or no (effects always)

**Four build documents, one per message:**

6. **Characters** — one plain prompt each, generated in Flow
7. **Story** — premise, beats, continuity, episode index
8. **Storyboard** — one row per scene, whole story
9. **Script** — dialogue with punch lines and sound

**Then, per episode:**

10. **Flow agent instructions** — one block, pasted once before anything is generated
11. **Episode story → script → scene count → prompts**, one scene per message

`next` means the next document. That's the whole vocabulary.

## What it enforces

**Plain prompts.** Every Flow prompt is one paragraph of continuous prose, 90–130 words: description, action, place, camera, light, style, dialogue and voice, ambience and effects, negatives, duration, ratio. No labels, no bullets, nothing to fill in.

**Four durations.** Flow generates 4, 6, 8 or 10 seconds — nothing else. Shots are generated long and trimmed to 2–4s. Longer action extends in 10s steps, to 40s.

**Scene by scene.** One scene per message, every shot its own copy block.

**Animals mean no humans.** Anthropomorphic animals walk upright, speak, wear clothes and use phones — but they look like animals. Species is cast for temperament and you can swap any. Then: no humans in frame, background, crowd, poster or reflection.

**Music is a choice; sound is not.** If you say no music, every prompt ends `No music.` — but thunder, doors, cars and footsteps are still written into every shot.

**Dialogue sounds spoken.** Contractions, fragments, interruptions. One punch line per scene, ten words or fewer, last before the cut.

**Characters are built once.** One plain prompt per character returns a four-view reference sheet. Attach that file to every shot. If the views drift, keep the front and generate the rest from it.

## Files

```
my-project/
├── project.md        language, platform, format, cast, music, aspect
├── story.md          premise, beats, continuity, episode index
├── characters.md     one plain prompt per character + voice
├── locations.md      one plain prompt per recurring place
├── storyboard.csv    one row per scene, whole story
├── script.md         whole-story script
├── flow-agent.md     standing instructions for Flow
└── ep01/
    ├── script.md     episode script
    └── prompts.md    scene by scene
```

## Formats

Reel movie · Reel shorts · Single Reel · YouTube Short · landscape short · long-form episode · ad · music video · trailer · documentary.

One skill, not ten. The format is a setting; each has a craft reference the model reads when it plans.

## Other languages

**Prompts are English. Dialogue is native.**

Spoken lines go into the prompt verbatim, in native script, with a locked voice descriptor:

```
He says in Malayalam: "അമ്മേ, എനിക്ക് പേടിയാകുന്നു."
Voice: low, warm, unhurried; Malayalam with a Thrissur accent.
```

No dubbing. No subtitles unless asked.

## Long projects

One scene per message, one episode per chat. Files over pasted text. The continuity rules live in `story.md`, not in the conversation.

## Honest limits

- Flow's UI is manual — nothing here triggers a generation.
- Character consistency is good, not perfect. Same reference plus verbatim description is the fix.
- Voices drift between clips the same way faces do.
- Talking heads are AI's weakest output.
- A 10-minute film is roughly 150–200 generations with retries.
- This is pre-production. The edit is where the film is actually made.
